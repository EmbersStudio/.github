## 🔥 关于我们

EmbersStudio 是一个由 CrimsonSeraph 发起的技术工坊，致力于全栈开发与跨平台创意作品。

目前团队核心成员专注于以下方向：

- 🌐 **Next.js + TypeScript 全栈**：构建高效、可扩展的 React 全栈应用
- 🎮 **游戏开发**：Unreal Engine（3D）& Godot（2D）
- 🖥️ **桌面应用**：Qt 框架（C++ / PyQt）
- 🐍 **脚本与工具**：Python 自动化 & 数据处理
- ⚙️ **系统级开发**：C++ 高性能后端与引擎底层
